# Any-chat kit

**Synthetic demonstration data.** Run both demos in any major LLM chat tool.

| File | Purpose |
|------|---------|
| `SCRIPT.html` / `SCRIPT.md` | Printable presenter script with timing marks, room questions, fallbacks and both Demo 2 endings |
| `REHEARSAL_CHECKLIST.md` | Paper pass/fail checklist for each rehearsal |
| `RUNBOOK.md` | Routes (paste or upload), reset checklist, pre-staging, on-stage steps, fallback, recording |
| `TOOL_CARDS.md` | Per-tool settings to clear and blanks to fill in at rehearsal (ChatGPT, Claude, Gemini, Copilot) |
| `paste/` | Demo 1 paste blocks (report + prompt, one per stage) and the Demo 2 prompt. Open in any text editor, copy, paste. |
| `REHEARSAL_LOG.md` | Per-tool log; Demo 2 live only after three successful rehearsals in that tool |
| `rehearsals/` | Optional: saved answers, for the maintainer to turn into the app's labelled fallback |

Nothing here needs Python or any install. The injected files stay in `../demo2/` only.
