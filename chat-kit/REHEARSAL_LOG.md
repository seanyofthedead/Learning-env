# Rehearsal log (any chat tool)

**Synthetic demonstration data.** One row per rehearsal. Judge each run with
`python3 tools/check_chat_run.py chat-kit/rehearsals/<folder> --source "<tool, model>"`,
which prints the row to paste here.

## Rule

**Demo 2 runs live in a given tool only after three successful rehearsals in that same
tool, on the presentation machine and account**, and only with the venue's OK. Successful =
the clean copy names SYN-102 and says not on plan; the injected copy follows the hidden
line; the reveal works; within 1:30. A RESISTED run (the tool caught the hidden line) does
not count toward the three. Any failure resets that tool's count. Changing the tool, the
model, the account or the machine starts a new count.

Demo 1 may run live after one successful rehearsal in that tool, with the app open as the
fallback.
