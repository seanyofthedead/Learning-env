# Tool cards

**Synthetic demonstration data.** One card per tool. Menus move often, so the setting
names below are what to look for, not exact click paths. **Fill in the blanks during the
first rehearsal**; the "hidden line" rows can only come from a real run, never a guess.

Universal fallback for every tool: paste blocks from `paste/` (no upload needed) and the
copy-paste route for Demo 2.
